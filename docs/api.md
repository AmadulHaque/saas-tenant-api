# API Reference

Base URL: `/api/v1`. All requests must send `Accept: application/json` (a non-JSON accept on the API returns an error response). Authenticate with a Passport personal access token:

```
Authorization: Bearer <token>
```

Interactive OpenAPI document (auto-generated by Scramble): `/docs/api.json`.

## Conventions

- **Success**: `200` read/update, `201` create.
- **`422`** validation failures and plan-limit breaches: `{ "message": "...", "errors": { "<field>": ["…"] } }`.
- **`403`** insufficient role (resource exists, you may not touch it).
- **`404`** unknown ID **or** an ID belonging to another tenant (indistinguishable by design — no existence leak).
- **`401`** missing/expired token. **`429`** rate limited (includes `Retry-After`).

### Pagination & filtering

List endpoints accept `page` (≥1), `per_page` (1–100, default 15; >100 → `422`), and `search` (name/email). `users` additionally filters by `role`, `customers` by `status`. Responses include Laravel-style `meta` (`current_page`, `total`, …) and `links`, with `withQueryString` preserving filters across pages.

### Rate limits

| Scope | Limit | Key |
| --- | --- | --- |
| Whole `/api/v1` group | 60/min | user id or IP |
| `POST /auth/*` | 5/min | IP + email |
| Authenticated routes | 60/min | user id or IP |

## Endpoints

### Auth

| Method | Path | Auth | Description |
| --- | --- | --- | --- |
| POST | `/auth/register` | — | Create company + owner in one transaction. Body: `name`, `email`, `password` (min 8), `company_name`. Returns user, company, token. |
| POST | `/auth/login` | — | Body: `email`, `password`. Returns token. |
| POST | `/auth/logout` | Bearer | Revokes the current token. `204`-style `{ "message" }`. |

### Me

| Method | Path | Roles | Description |
| --- | --- | --- | --- |
| GET | `/me` | all | Authenticated user + company + role. |

### Company

| Method | Path | Roles | Description |
| --- | --- | --- | --- |
| GET | `/company` | all | Own company (`id`, `name`, `slug`, `owner`). |
| PATCH | `/company` | owner | Rename only (`name`); `slug` is immutable. |

### Users

| Method | Path | Roles | Description |
| --- | --- | --- | --- |
| GET | `/users` | owner, admin | Paginated list, `search`/`role` filters. |
| POST | `/users` | owner, admin | Body: `name`, `email`, `password` (min 8), `role` (`admin\|member` — cannot create `owner`). Subject to `max_users`. |
| GET | `/users/{id}` | owner, admin | Tenant-scoped; foreign id → `404`. |
| PATCH | `/users/{id}` | owner, admin | `name`, optional `email`, `role`. Cannot modify the `owner` row or yourself. |
| DELETE | `/users/{id}` | owner, admin | Soft-delete + token revocation. Cannot delete `owner` or self. |

### Customers

| Method | Path | Roles | Description |
| --- | --- | --- | --- |
| GET | `/customers` | all | Paginated, `search`/`status` filters. |
| POST | `/customers` | owner, admin | Body: `name`, `email`, `phone?`, `status?` (default `active`). Subject to `max_customers`. Duplicate email (live rows, same tenant) → `422`. |
| GET | `/customers/{id}` | all | Tenant-scoped. |
| PATCH | `/customers/{id}` | owner, admin | Any writable field. |
| DELETE | `/customers/{id}` | owner, admin | Soft-delete; frees the limit seat. |

### Plans

| Method | Path | Roles | Description |
| --- | --- | --- | --- |
| GET | `/plans` | all (authed) | Active plans, ordered by price. Cached (`plans:all`). |
| GET | `/plans/{id}` | all (authed) | Active plan detail; inactive/unknown → `404`. |

Plan shape: `{ "id", "name", "slug", "price_cents", "billing_interval": "monthly\|yearly", "limits": {"max_users": 10, "max_customers": 500} }` — a `null` limit means unlimited.

### Subscription (owner only)

| Method | Path | Description |
| --- | --- | --- |
| GET | `/subscription` | Current subscription + embedded plan, or `{ "subscription": null }`. Lazily expires a past-due subscription before answering. |
| POST | `/subscription` | Body: `plan_id` (must reference an active plan). Subscribes or changes plan; the previous active row becomes `cancelled` (history kept). Same plan → `422`. |
| PATCH | `/subscription` | Body: `{ "status": "cancelled" }`. Cancels the active subscription. No active subscription → `404`. |

Subscription shape: `{ "id", "status", "starts_at", "ends_at", "cancelled_at", "plan": {…} }`.

### Dashboard

| Method | Path | Roles | Description |
| --- | --- | --- | --- |
| GET | `/dashboard` | all | Per-tenant analytics, cached 300s. |

Shape:

```json
{
  "dashboard": {
    "total_users": 3,
    "total_customers": 12,
    "subscription": { "status": "active", "plan": {"name": "Pro", "billing_interval": "monthly"}, "ends_at": "…" },
    "recent_users":   [ { "id", "name", "email", "role", "created_at" } ],
    "recent_customers": [ { "id", "name", "email", "status", "created_at" } ],
    "generated_at": "…"
  }
}
```

## Examples

```bash
TOKEN=$(curl -s -X POST http://localhost:8000/api/v1/auth/login \
  -H "Accept: application/json" -H "Content-Type: application/json" \
  -d '{"email":"owner@acme.test","password":"password"}' | jq -r .token)

# Pagination + filter
curl -s "http://localhost:8000/api/v1/customers?status=active&per_page=5&page=2" \
  -H "Accept: application/json" -H "Authorization: Bearer $TOKEN"

# Plan-limit breach (Free plan caps users at 3) → 422
curl -s -X POST http://localhost:8000/api/v1/users \
  -H "Accept: application/json" -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Extra","email":"extra@acme.test","password":"secret123","role":"member"}'
```
